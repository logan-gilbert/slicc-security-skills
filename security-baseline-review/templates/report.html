Methodology. Static analysis of the delivered repository (secrets, DOM XSS sinks, CSP/header configuration, CORS, third-party integrity, dependency manifest, published data, error handling) combined with live checks in a real browser: security headers on each reviewed page, cookies, resources actually loaded, request URLs, and HTTPS enforcement. Light, non-destructive probes were limited to a cross-origin GET, a request for a non-existent path, and (where protected URLs were supplied) a comparison of responses with and without the reviewer's session. No fuzzing, brute-force, authentication bypass, or payload injection was performed. Judgment items marked AI-assisted were assessed by an AI reviewer and confirmed by the named reviewer.
